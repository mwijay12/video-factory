# _archive/

This directory contains historical scripts used during VideoFactory's
development. They are kept for reference but are NOT part of the main application.

## legacy_fixes_2026/
One-off scripts that patched specific bugs during development (fix_*.py, patch_*.py, etc.).
Most have been superseded by the proper implementation in src/.

## sync_experiments/
Experimental scripts for syncing MoviePy audio (add_sync.py, add_method.py).
Superseded by src/video/video_engine.py.

---
Do not import or run these scripts in production.
